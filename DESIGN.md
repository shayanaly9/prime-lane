# DESIGN.md

## Color Strategy: Committed
The brand uses a primary teal accent (#1A7A62) against a premium off-white (#F7F5F0) background, with deep navy (#0B1220) for hierarchy and contrast.

### Palette (OKLCH inferred)
- **Primary Teal**: `oklch(45% 0.12 165)` / #1A7A62
- **Background Light**: `oklch(96% 0.01 85)` / #F7F5F0
- **Ink Dark**: `oklch(18% 0.04 260)` / #0B1220
- **Lane Branding**: `oklch(62% 0.16 115)` / #639922

## Typography
- **Headings**: Raleway (300-800)
- **Body**: Open Sans (400-600)
- **Hierarchy**: Large heading scale with significant weight contrast.

## Layout & Rhythm
- **Spacing**: Varied rhythm using responsive padding.
- **Components**: Spotlight cards, reveal-on-scroll sections.
- **Containers**: Max-width constraints on body text (75ch).

## Motion
- **Entry**: Scroll-triggered reveals with cubic-bezier(0.32, 0.72, 0, 1).
- **Interactive**: Hover spotlights and subtle transitions.

## Effects
- **Grain**: Global SVG noise overlay at 3.2% opacity.
- **Glass**: Rare, purposeful use of translucent surfaces.
